AUTHENTICITY AND CAPTURE
Production Godot 4.7 game model and MainScene, seed 207, normal mode, no training.
The corner heuristic chooses a legal direction at 3 inputs per simulated second.
Each candidate move is evaluated only after discarding its random spawn, so the
policy does not know the next random birth. This is automated demonstration play.

Every model step is 1/30 second. Intervals between the three selected clips are
simulated offline without recording. The filmed intervals use 1 simulated second
per 1 video second. Moves enter queue_move; skills enter queue_item and cost their
normal earned gold. The tool never sets board cells, HP, gold, enemy state, damage,
threat thresholds, Boss state or random outcomes in the live model.

The same production rendering code draws real movement, merges, spawns, combat,
health bars, spells and the Japanese UI. Game logic keeps running during recording;
no pause menu is used. Only the small bilingual montage/section caption is added.
No AI-generated gameplay motion, external compositing, fake HUD or image retouching.
The game itself uses its existing released visual and audio assets.

AUDIO AND EDITING
Godot Movie Maker records the game's actual AudioStreamPlayer output: merge,
attack, summon and skill effects, plus the two in-game BGM tracks. Capture does not
rewrite the user's sound settings. It uses presentation volumes 0.55 music / 0.70 FX.
BGM playback seeks to the simulated run time at the two labelled editorial cuts.
There is no voice-over or added third-party soundtrack.

Editing: hard cuts between the three real intervals; opening video fade 0.18 s;
opening audio fade 0.10 s; ending picture/audio fade 0.50 s; uniform audio gain +7 dB.
The source game music and effects are mixed and AAC encoded for this video.
No gameplay is sped up inside the shown intervals.

REPRODUCE FROM PROJECT ROOT
bash game/tools/make_gameplay_video.sh

Requirements: Godot 4.7 with the native macOS renderer; FFmpeg/ffprobe with libx264.
Default executable paths are /opt/homebrew/bin/{godot,ffmpeg,ffprobe}; override with
GODOT_BIN, FFMPEG_BIN, FFPROBE_BIN if needed. Imported project assets are required.
The capture tool is game/tools/capture_gameplay_video.gd. A headless -- --scan option
runs the same progression to validate clip states, without making video.

The shell script writes a temporary Movie Maker AVI into a unique temporary folder,
encodes an H.264 yuv420p / BT.709 limited-range MP4 with AAC stereo 48 kHz, enables
faststart, saves the poster and ffprobe metadata, then deletes the intermediate AVI.
Product code, exported game builds and website files are not changed by capture.
